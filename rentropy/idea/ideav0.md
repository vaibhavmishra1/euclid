Rentropy

The idea is based on improvement on R-Zero framework.
https://github.com/Chengsong-Huang/R-Zero.git

the idea is as such - 

stage 1-
in this stage we gather various mathematical questions from datasets such as MATH, gsk8k, and others.
we use a teacher model to solve the problem and extract certain concepts from these problems.
we group the question concepts pair as (Q,Cs)
we create a set of various concepts and treat them as various class labels.

stage 2- we use the Qwen/Qwen3-Embedding-0.6B model to extract the embeddings of all the 
questions, we then do a multi class classification with input as the question embedding 
and output as the concept set, using a feed forward network F.

stage 3-
given the feedforward network F, we can classify any question into its corresponding concepts.

stage 4- 
we now come to R-Zero, 
in the r-zero experiment, the author talks about the problem of model entropy collapse where the model forgets to create diverse samples with time and converges to a given policy hence the model does not improve with iterations. this is shown by the fact that top-1 accuracy increase but top-k accuracy remains the same or worse showing that the model policy only learns to improve from its k diverse local reasoning patters and it does not add any reasoning capabilities in diverse problems. the reward is calculated using majority voting over n different samples. 

stage 5- 
we introduce a new kind of reward called the diversity reward where a question Q generated by the challenger is first rewarded based on majority voting and then the question is then fed to our classifier F to find out the concept cluster to which it is based on.

stage 6- 
we keep a memory of various clusters and find out how unlikely it was to choose that concept cluster, basically if the model generates a question which belongs to a rare cluster or is different from other n-1 questions concept clusters then it is rewarded with a higher diversity reward given that the it falls in the threshold of majority voting.

stage 7- we apply GRPO based on the combination of maj voting + diversity reward .

stage 8- wwe can theoritically prove that our model favours exploration to diverse questions without collapsing with generating questions from a particular cluster hence is more exploratory.
